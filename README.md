# Flick Soccer LAN

Juego 2D de fútbol de fichas para **dos jugadores en red local (LAN)**, hecho en **Processing**. Se juega como el billar: arrastrás una ficha hacia atrás, la soltás como una gomera y sale disparada hacia la pelota.

## Cómo se juega

- Cada equipo tiene **5 jugadores y un arquero** (el arquero es un 15% más grande que las demás fichas).
- Para tirar, **hacé clic en una ficha, arrastrá hacia atrás y soltá**. Cuanto más arrastrás, más fuerte sale.
- Las fichas chocan entre sí y con la pelota.
- **Gana el primero que llega a 5 goles.** Cuando alguien hace un gol, sale confeti.
